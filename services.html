我们能做的事

四个方面，十八类工作。第一个项目从其中一类开始，具体做哪一类由诊断决定。

把数据看清楚

先有一份全公司都认的数字。

销售额386.2万元
毛利率30.4%

  • 数据整理和指标定义

    把进销存、财务系统和各种表格里的数据接到一起，清洗干净。每个指标只留一种算法，由您的负责人确认。

  • 经营看板和报表

    每周自动生成的经营报表，和可以点击查看的看板：趋势、排名、对比、地图和明细。

  • 数据问答

    用平时说话的方式提问，系统从您的数据里查出数字，并写明用的指标定义和时间范围。

  • 专题分析报告

    针对一个具体问题写给管理层的报告，例如线上线下比价、门店评估。有结论，有依据，有建议。

把决策算清楚

把经验里的判断写成可以计算、可以检验的规则。

  • 定价和促销

    线上线下比价，调价规则，不同商圈的差别定价。先在少数门店试，再推广。

  • 需求预测

    按门店、按品种预测销量，用于订货、排班和促销备货。

  • 库存和补货

    安全库存和补货建议，缺货和滞销的预警，多个供应商之间的订货分配。

  • 品类和选品

    给商品分类分组，提出淘汰和引进的建议，必须保留的品种设保护规则。

  • 门店网络和选址

    找出位置不合理的门店，给出开店、关店和并店的建议。

  • 排班、排产和配送

    把人员排班、生产排程和配送路线写成优化问题来求解，约束条件由您确认。

把重复的工作交出去

模型做重复的部分，人做确认。

  • 业务智能体

    把一项重复的判断工作交给智能体，例如品类淘汰、补货建议、比价和对账。每条建议都由您的员工确认。

  • 文档识别和录入

    把纸质文件和照片识别成文字，再按栏目整理成表格，例如单据、合同和产品说明书。认不清的地方标出来，由人核对后入库。

  • Skill

    把一项工作的步骤、规则和例子写成模型可以照着执行的说明。换人、换模型，这项工作的做法都留在企业里。

  • Harness

    搭建模型运行的环境：能调用哪些工具、读哪些数据，每一步留下记录，出错时停下并通知人。

让系统用得住

模型怎么接，效果怎么验，人怎么带。

调用 API上线快，成本低
私有化部署数据不出内网

两种方式用同一套测试题验收

  • 模型接入

    用在中国内地正式提供服务的模型，例如 DeepSeek。可以调用 API，也可以把开源模型部署在您自己的服务器上。用 API 时，哪些数据可以发给模型，事先写进协议。

  • 效果检验

    一项改动有没有用，用试点和对照来检验：先在几家门店做，和没有做的门店比较。

  • 员工培训

    教管理层和一线员工用 DeepSeek 等国内已经正式上线的模型，配教材和实操练习。每件事送一场前沿 AI 使用课。

  • 招聘把关

    您自己招人时，可以单独委托我们把关，不做项目也可以。我们按岗位要求出题，每位候选人做一次上机测试，出一份报告，每人 0.2 万元。我们不寻访，也不推荐人选。

第一个项目可以做什么

下面是五类客户常见的第一个项目。具体做哪一个，由诊断决定。

  • 连锁零售

    • 每周的门店经营报表和数据问答
    • 线上线下价格对比和定价
    • 品种的保留和淘汰
    • 单据和说明书的识别录入
    • 门店的关、并、开

  • 制造企业

    • 订单、生产和库存的每周报表
    • 交期和缺料的预警
    • 报价和成本的核算

  • 商贸企业

    • 销售、毛利和应收账款的每周报表
    • 库存周转和缺货
    • 客户和品种的贡献分析

  • 物流和供应链

    • 运输、仓储和订单的每周报表
    • 配送路线和车辆排班
    • 到货延误和库存不足的预警

  • 医疗机构

    • 医护、诊室和手术室的排班
    • 就诊量和预约量的预测
    • 药品和耗材的库存预警

    医院、诊所、医美和口腔机构都适用。

  • 其他行业

    不在这几类里也可以谈。第一个项目做什么，由诊断决定。
